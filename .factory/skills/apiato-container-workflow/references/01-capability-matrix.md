# Capability Trigger Matrix

Mục `(optional)` không có nghĩa được bỏ tùy ý. Khi trigger đúng, toàn bộ bước liên quan trở thành bắt buộc.

| Capability                | Trigger                                                                                                                                | Thứ tự bắt buộc                                                                                                                                                                                                                                                                  |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Container dependency      | Feature gọi Model/contract Container khác                                                                                              | Chốt contract → hoàn thiện dependency foundation → migrate/test độc lập → mới integration                                                                                                                                                                                        |
| Generator                 | Container chưa tồn tại                                                                                                                 | Chạy `--help` → chọn `create-api` hoặc `apiato:generate:container` → ghi rõ từng lựa chọn → audit file sinh ra                                                                                                                                                                   |
| Config                    | Có MIME, limit, status, role, default, provider map                                                                                    | Tạo config → model/domain getter dùng config → Request và Task dùng cùng source → test override                                                                                                                                                                                  |
| Model foundation          | Có model/table mới                                                                                                                     | Ship Parent → `$table` → `getTableName()` → fillable/casts/hidden/resourceKey → factory                                                                                                                                                                                          |
| Accessor/mutator          | Giá trị lưu và domain/API khác nhau                                                                                                    | Cast trước → accessor/mutator chỉ normalize invariant → không query/side effect → test persist/serialize                                                                                                                                                                         |
| Domain getter/helper      | Có derived value hoặc config lookup                                                                                                    | Đặt tên theo nghiệp vụ → giữ pure nếu có thể → không query ẩn trong collection → unit test                                                                                                                                                                                       |
| Static model method       | Có helper static dùng Eloquent inherited method                                                                                        | Dùng `static::` khi cần late static binding → hard-code class chỉ khi cố ý                                                                                                                                                                                                       |
| MySQL optimization review | Có Migration/schema/index, relation, Repository/query, search/filter/sort, pagination, transaction, locking/concurrency hoặc bulk data | Gọi `mysql-optimization` → chốt data types/nullability → index strategy/leftmost prefix → query shape → offset/deferred-join/keyset decision → keyset stable order/tie-breaker/cursor predicate/index nếu dùng → lock/deadlock risk → EXPLAIN validation → schema/index rollback |
| Migration                 | Thêm bảng/cột                                                                                                                          | Chốt schema/delete/snapshot → import Model → `getTableName()` → columns → relation columns → FK → delete constraint → indexes/unique → up/down/up                                                                                                                                |
| Expand-Migrate-Contract   | Đổi schema/data contract đang chạy production                                                                                          | Expand compatible → backfill/migrate data → deploy readers/writers mới → contract cũ sau                                                                                                                                                                                         |
| Relation                  | Có owner/parent/child/membership                                                                                                       | Cả hai Model/Migration tồn tại → relation methods → inverse relation → eager-load/query tests                                                                                                                                                                                    |
| Polymorphic relation      | Một resource thuộc nhiều owner types                                                                                                   | Allowlist/morph map → morph columns/index → `morphTo` → owner relations → không nhận FQCN từ client → cross-owner tests                                                                                                                                                          |
| Custom Pivot              | Pivot có role/status/active/main/casts/events                                                                                          | Pivot Model → table/casts → `using()` → `withPivot()` → `withTimestamps()` → `wherePivot*()`                                                                                                                                                                                     |
| JSON field                | Dynamic structure sống cùng lifecycle root                                                                                             | Chốt shape/size/version → migration JSON → casts → nested validation → không dùng khi cần report/filter độc lập                                                                                                                                                                  |
| Snapshot                  | Source có thể đổi/xóa nhưng lịch sử phải đúng                                                                                          | Chốt truth-at-time → columns/versioned JSON → copy trong create transaction → immutable/update policy → source-change/delete tests                                                                                                                                               |
| SoftDelete                | Root cần restore/grace period/trash                                                                                                    | Migration softDeletes → Model trait → delete → cause flags → restore → purge schedule → file cleanup → tests                                                                                                                                                                     |
| Cascade soft delete       | Child phải theo parent                                                                                                                 | `deleted_by_*` → Event/Listener hoặc booted → chunk cascade → restore đúng cause → force purge                                                                                                                                                                                   |
| Model `booted()`          | Hook phải chạy trên mọi Eloquent lifecycle path                                                                                        | Chọn event phase → callback nhỏ → `updateQuietly()` khi tự update → explicit event → after-commit side effect                                                                                                                                                                    |
| Domain permission         | Có owner/member/private/hidden                                                                                                         | Parent chain → `canView/canEdit/canDelete` → Request access → Task mutation check → list criteria → preload permission data                                                                                                                                                      |
| Hash ID                   | ID đi qua API                                                                                                                          | Response `getHashedKey()` → Request `$decode` → route `$urlParameters` → hashed tests                                                                                                                                                                                            |
| Repository                | Model có data access                                                                                                                   | Model binding → safe `$fieldSearchable` → criteria surface → indexes khớp filters                                                                                                                                                                                                |
| List/search/filter        | API collection                                                                                                                         | Query validation/cap → RequestCriteria → ownership criteria → eager load/count/exists → paginate → docs                                                                                                                                                                          |
| Sort/reorder              | Client thay thứ tự                                                                                                                     | Backend scope owner → batch-load IDs → unique/ownership check → lock/transaction → batch update → concurrency tests                                                                                                                                                              |
| N+1 prevention            | Collection/includes/permission/statistics/realtime many recipients                                                                     | Trace Task → Model methods → Transformer → preload/withCount/withExists → `relationLoaded()` → query-count test                                                                                                                                                                  |
| Factory                   | Tests/seeder cần fixture                                                                                                               | Factory fields hợp lệ → states theo invariant → relations → factory test                                                                                                                                                                                                         |
| Seeder                    | Default data/permission/onboarding                                                                                                     | Idempotent seed → config-aligned data → relation ordering → environment guard → rerun test                                                                                                                                                                                       |
| Task decomposition        | Use case có nhiều thao tác                                                                                                             | Liệt kê atomic jobs → một Task/mục đích → scalar/array input → Repository → exceptions                                                                                                                                                                                           |
| SubAction                 | Sub-use-case được nhiều Actions dùng                                                                                                   | Tách orchestration tái sử dụng → gọi Tasks → không thay Task cho một query đơn                                                                                                                                                                                                   |
| Transaction               | Ghi nhiều bảng/sync pivot/file metadata/log/history                                                                                    | Chọn owner theo pattern repo → lock nếu race → core writes → commit → side effects → rollback trước throw                                                                                                                                                                        |
| Concurrency/locking       | Limit, stock, balance, primary, reorder                                                                                                | Chọn lock owner/unique constraint → kiểm tra invariant trong transaction → concurrent tests                                                                                                                                                                                      |
| Storage/media             | Upload/replace/delete file                                                                                                             | Config MIME/size/count → validate → server-owned path → store → DB transaction → compensate orphan → URL helper → cleanup                                                                                                                                                        |
| Event                     | Domain state change cần reaction                                                                                                       | Chọn dispatch point → minimal immutable payload → dispatch sau successful state change → event test                                                                                                                                                                              |
| Listener                  | Reaction tách khỏi core use case                                                                                                       | Một side effect → Task/Action call → idempotent → queue/afterCommit nếu external → provider registration                                                                                                                                                                         |
| Notification/mail         | Gửi thông báo                                                                                                                          | Recipients/visibility → snapshot payload → queued delivery → afterCommit → dedup → Notification/Mail fake                                                                                                                                                                        |
| Job/queue                 | Slow/external/eventual side effect                                                                                                     | Xem `03-queue-worker-runtime.md` → payload ID/DTO → idempotency → retry/failure → queue routing → worker/deploy                                                                                                                                                                  |
| Scheduler                 | Recurrence/purge/import polling                                                                                                        | Command/Job → chunk → withoutOverlapping → onOneServer nếu multi-node → cron runtime → duplicate tests                                                                                                                                                                           |
| Realtime/broadcast        | UI cần cập nhật tức thời                                                                                                               | Recipient scope → stable Transformer payload → afterCommit queue → event ID/idempotency → no external I/O in constructor                                                                                                                                                         |
| File cleanup              | Delete/replace/force purge                                                                                                             | Snapshot paths → DB success → afterCommit Listener/Job → idempotent missing-file behavior → orphan tests                                                                                                                                                                         |
| Audit/log/history         | Business cần trace                                                                                                                     | Origin snapshot → log fields/user/time → same transaction nếu core → immutable policy → tests                                                                                                                                                                                    |
| Auth/Passport             | Login/token/social/verification/reset                                                                                                  | Dùng `apiato` + `laravel-duong` auth refs → actor/client/credential → issue/refresh/revoke → scopes/TTL → security tests                                                                                                                                                         |
| Cache                     | Hot read có stable permission/invalidation                                                                                             | Permission-aware key → TTL/freshness → invalidation events → stampede/leak tests                                                                                                                                                                                                 |
| Rate limit                | Login/OTP/reset/search/import abuse-prone                                                                                              | Actor/IP key → cap/window → error contract → tests/monitoring                                                                                                                                                                                                                    |
| API Transformer           | Resource trả JSON                                                                                                                      | Public fields → hashed IDs → includes → no secrets/raw FQCN/path → no DB query                                                                                                                                                                                                   |
| API docs                  | Route/payload/query/response đổi                                                                                                       | `@apiParam/@apiBody/@apiQuery` → permissions/includes/filter docs → generate warning-free                                                                                                                                                                                        |
| Unit/Functional tests     | Behavior thay đổi                                                                                                                      | TDD → Task/Action/domain unit → Route functional → success/422/401/403/404/edge                                                                                                                                                                                                  |
| Side-effect tests         | Event/queue/storage/notification                                                                                                       | Fake dispatch → direct handle test → rollback no-dispatch → retry/idempotency/missing model                                                                                                                                                                                      |
| Runtime/deploy            | Migration/config/provider/queue/scheduler/storage/auth đổi                                                                             | Migration plan → caches → worker restart → scheduler health → storage access → smoke/rollback                                                                                                                                                                                    |

## Capability activation rules

```txt
file/media present          -> Config + Storage + Transaction + Cleanup + Tests
multiple owner types        -> Dependency closure + Polymorphic + Cross-owner tests
limit/primary/reorder       -> Concurrency + Locking + Transaction
historical record           -> Snapshot
delete/restore              -> SoftDelete matrix + Cleanup
external side effect        -> Event/Listener/Job + afterCommit + Runtime
background/delayed work     -> Queue + Worker + Failed-job runbook
scheduled work              -> Scheduler + Worker + overlap prevention
list endpoint               -> Criteria + Pagination + Index + N+1 audit
private resource            -> Domain permission + Hash ID + scope criteria
route contract changed      -> Functional tests + apidoc
schema/query/locking present -> mysql-optimization + index/query/lock/EXPLAIN/rollback contract
```
